# Script library

Every `.jsx`, `.jsxbin` and `.ffx` file in this folder shows up in the **Scripts** category of MenMen Workflow.
Click one to run it (`.ffx` presets are applied to the selected layers). Scripts can be favorited, docked
and added to user panels like any other tool.

MenMen also scans your personal folder, which survives extension updates:

- macOS: `~/Documents/MenMen Workflow/Scripts`
- Windows: `Documents\MenMen Workflow\Scripts`

After adding files, click **Refresh** in the Scripts category (or ☰ ▸ Refresh Scripts).

Files in this folder are ignored by git (see `.gitignore`) so third-party scripts are not published
with the repository. Only commit scripts you have the right to redistribute.
